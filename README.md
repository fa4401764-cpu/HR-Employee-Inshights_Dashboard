# 👥 HR Employee Insights Dashboard

 1-Project Title:                                                                           
HR Employee Insights Dashboard                                                                                                  

2-Short Description:                                                                                                  
The HR Employee Insights Dashboard is a comprehensive and interactive dashboard developed in Power BI Desktop to analyze workforce data and provide valuable insights into employee distribution, salary expenses, allowances, and bonuses across different departments, cities, genders, and designations.                                                                                                                                 
It transforms raw HR data into meaningful visual analytics, enabling HR professionals and management to monitor organizational workforce structure, compensation trends, and departmental performance. Through dynamic slicers, KPI cards, and interactive charts, users can quickly identify key patterns and make data-driven human resource decisions.                                                                       

3-Tech Stack:                                                                                                                                  
• Power BI Desktop – Dashboard development and visualization                                                     
• Power Query – Data cleaning and transformation                                                                         
• Data Analysis Expressions (DAX) – KPI calculations and custom measures                                                         
• Microsoft Excel / CSV – Data preparation and preprocessing                                                                      
• Data Visualization Techniques – KPI cards, donut charts, bar charts, tables, slicers, and filters                                     

4- Data Source
Source Website: Kaggle.com

5-Dashboard Features:  

📊 Interactive Slicer Settings                                                         
• Dedicated slicer panel for easy filtering.                                                               
• Reset button to clear all selected filters instantly.                                                  
• Filters available for: Department ,City                                                        
•Dynamic visuals update automatically based on selected criteria.    

📌Workforce Overview KPI Cards:                                                               
•The dashboard displays high-level summary metrics, including:  Total Employees,Total Salary , Total Allowances ,Total Bonus                   
•These KPI cards provide an instant overview of workforce size and compensation costs.                                           

🚻 Employee Distribution by Gender                                                                                   
•Interactive donut chart showing male and female employee counts.                                                                           
•Percentage share of each gender is displayed.                                                                                    
Example: Female: 560 employees (53.33%) ,Male: 490 employees (46.67%)                                                                             
•This visualization helps assess gender diversity within the organization.                                                             

💼 Salary Distibution by Designation:                                                                                          
•Horizontal bar chart comparing salary expenditures across job roles.                                                                        
•Includes designations such as: Executive ,Manager ,Assistant Manager ,Senior Officer ,Analyst                                            
•Useful for understanding compensation allocation by position level.                                                                                                        

📈 Key Performance Indicators (KPIs):                                                                                   
•Gender Ratio                                                                                                                   
•Department-Wise Employee Count                                                                                                     
•Department-Wise Salary Distribution                                                                                                
•City-Wise Compensation Summary                                                                                                

📊 Visualizations:                                                 
•KPI Cards                                                                       
•Donut Chart                                                                                    
•Horizontal Bar Chart                                                                                                                            
•Matrix/Table                                                                                          
•Slicers                                                                                                                 
•Reset Button                                                                                                   
•Cross-Filtering Interactions
